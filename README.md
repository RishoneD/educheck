## מפת דרכים

### גרסה 0.4 (נוכחית)
- זיהוי מקצוע/מורה לפי תלמיד (תמיכה בכמה מורים לאותו מקצוע)
- זיהוי הערות בנק לפי טקסט (ללא קוד) עם תמיכה בגרסאות מגדר ובהערות מורחבות
- הצגת טקסט ההערה לצד מספר הקוד בדוח
- תיקון בדיקת ציון שנתי: לא נבדק ציון מחצית א' בתעודות שנתיות

### גרסה 0.5 (בפיתוח)
- מדריך למשתמש — הסבר שלב-שלב כיצד להפיק קובץ ממאשב
- טופס משוב מובנה ודיווח תקלות
- מנגנון עדכונים אוטומטי לרשימת תקלות ידועות

### גרסה 1.0
- בדיקת ציוני כבוד
- בדיקת היעדרויות ואיחורים

### גרסה 2.0
- מצב ADMIN — ממשק לעדכון מאגר הערות הבנק ותנאי הבדיקה ללא עריכת קוד
